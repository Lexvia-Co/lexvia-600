# VBER applicant content

Identify the applicant and the step using the [applicant workflow](../../../README.md#applicant-workflow). The initial guide covers one adult preparing their own Tourist stream application from outside Australia. VBER helps them prepare a draft. They lodge and pay through ImmiAccount.

## Write and review the interface

- Write everyday actions and explanations in natural Mandarin using simplified Chinese characters. Preserve official wording such as `Visitor visa (subclass 600)`, `Tourist stream`, and `ImmiAccount`. Explain an unfamiliar term in Mandarin on first use when it helps the reader.
- Name the action the control actually performs. Use “保存草稿” for saving in VBER and “前往 ImmiAccount” for a link that opens the government service.
- When reviewing a page, check its shared layout, sign-in controls, metadata, accessible labels, and errors as well as visible body text. Check that the HTML language declaration matches the Chinese content, for example `lang="zh-CN"`. Give the location and a concrete replacement for each issue.

## Verify guidance and evidence

- Check each new or changed visa claim against the relevant section of the official stream page. Confirm that its stream, applicant location, and conditions match the text. If the source does not substantiate a claim, flag it for verification. Link to live Home Affairs information for fees and processing times. [Tourist stream for applicants outside Australia](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/visitor-600/tourist-stream-overseas)
- Preserve the force of the source. Use “必须” only for a verified requirement and state whom it applies to. Introduce examples with “例如” or “可以提供”. For instance, “你可以提供近期银行对账单等材料，说明你有足够的资金支付在澳期间的开支。” Direct applicants to their own ImmiAccount document checklist for the items requested in their case. [Visitor application guidance](https://immi.homeaffairs.gov.au/check-twice-submit-once/visitor-visa)
- Store the supporting official link and the date actually checked (`YYYY-MM-DD`) alongside each changed guide section or checklist rule in the version-controlled content. In a read-only review, report the source and review date with the finding.
